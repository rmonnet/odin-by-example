# Odin by Example

## Odin in a Nutshell

Odin is an imperative language in the tradition of C, Pascal, and Modula.
It is strongly typed and use manual memory management and can be used as a replacement for tasks where you would reach for C.

Odin's toolchain comes with the source code for the entire standard library as well as some vendor package (mostly graphics).
This gives you a tremendous opportunity to learn by reading the actual source code. Odin is available on the three major platforms (Windwso, macOS, and Linux).

If you are completely new to Odin, you should check the [Getting Started](https://odin-lang.org/docs/) to install the compiler.
